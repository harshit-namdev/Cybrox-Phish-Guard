# PhishGuard: Real-Time Phishing Link Detector 🛡️

PhishGuard is your first line of defense against the growing threat of phishing attacks. 🎣 This Chrome extension works tirelessly in the background, scanning every URL you visit in real-time to ensure your safety. By leveraging the power of the Google Safe Browsing API, PhishGuard provides proactive protection, helping you avoid malicious websites and potential scams.

## Features ✨

- **Real-time URL scanning 🚀:** PhishGuard examines URLs the moment you click on them, providing immediate feedback on their safety. This ensures that you're always aware of potential threats before they can harm you.
- **Color-coded warnings (red for dangerous 🔴, green for safe 🟢):** The extension uses a simple and intuitive color-coding system to alert you to the safety of a website. Green indicates a safe site, while red warns you of a potentially dangerous one. This visual cue makes it easy to quickly assess the risk associated with a URL.
- **Phishing reporting capability 🚨:** If you encounter a website that you believe is a phishing attempt, you can easily report it to PhishGuard. This helps improve the accuracy of the extension and protect other users from similar threats.
- **Statistics tracking for scanned and blocked URLs 📊:** PhishGuard keeps track of the number of URLs it has scanned and the number of phishing attempts it has blocked. This provides you with valuable insights into the effectiveness of the extension and the level of protection it provides.
- **User-friendly warning page with detailed threat information ℹ️:** When PhishGuard detects a potentially dangerous website, it displays a user-friendly warning page with detailed information about the threat. This allows you to make an informed decision about whether to proceed to the website or return to safety.

## How it Works ⚙️

PhishGuard actively protects you by:

1.  Scanning URLs in real-time using the Google Safe Browsing API.
2.  Comparing each URL against a database of known phishing websites.
3.  Displaying a warning page if a potential threat is detected.

This process happens seamlessly in the background, ensuring continuous protection without interrupting your browsing experience.

## Usage

- The extension icon will show green when protection is active
- Click the extension icon to view statistics and report phishing
- When accessing a suspicious URL, a warning page will appear
- Users can choose to go back (recommended) or proceed with caution

## Security Notes

- Never disable the extension when visiting unfamiliar websites
- Always report suspected phishing attempts
- Keep the extension updated with the latest threat definitions

## Project Description

PhishGuard is a Chrome extension designed to protect users from phishing attacks by scanning URLs in real-time using the Google Safe Browsing API. It provides color-coded warnings and allows users to report suspected phishing sites.

## Technical Details

The extension uses:
- Chrome Extensions Manifest V3
- Google Safe Browsing API v4
- Local storage for statistics
- Real-time URL checking
